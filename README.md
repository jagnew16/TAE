# TAE Class Project — AAA Sales Assistant

AAA is an AI sales assistant for sales reps, delivered through Microsoft Teams. It covers prospect research (BDSA), contact discovery (ZoomInfo), CRM duplicate checks and lead creation, follow-up reminders, and monitoring customer websites and Instagram for product launches.

## Where things are

- [`docs/business-requirements.md`](docs/business-requirements.md): the requirements we're building against. Start here.
- [`access-test/`](access-test/README.md): a check that each collaborator (and their AI tools) can read and write to this repo.
